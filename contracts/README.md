# Contracts

This directory will contain machine-readable contract files after the contract design phase.

The authoritative interface contracts are documented in `CONTRACTS.md` at the repository root.

## Planned Contents

The `contracts/schemas/` subdirectory is reserved for:

- OpenAPI specification
- JSON schemas
- Model I/O schemas
- Event schemas

These files are NOT yet created. They will be generated or written during the contract design phase, after the architecture stabilizes.
